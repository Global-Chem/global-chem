\## Contribution



This contribution adds the chemical constituent library for the whole plant

material of \*Mollugo cerviana\* (L.) Ser.



The Python chemical library contains reported chemical constituents with

SMILES structures. SMARTS representations are generated from the chemical

structures using RDKit.



\## Chemical Information



The chemical information was collected from published scientific literature

and chemical structure databases.



The contribution is restricted to the single plant material:



\*Mollugo cerviana\* (L.) Ser. — whole plant.
